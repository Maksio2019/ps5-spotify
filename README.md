# ps5-spotify: PS5 Speaker

Spotify Connect speaker for a jailbroken PS5: pick **PS5 Speaker** in the Spotify app and the music plays on
the console, also during games. Experimental, shelved (October 2026).

- **Code, README (install, run, build, known issues):** branch
  [`spotify-speaker`](https://github.com/Maksio2019/ps5-spotify/tree/spotify-speaker)
- **Payloads to download:** [Releases](https://github.com/Maksio2019/ps5-spotify/releases)
- This `main` branch only hosts the tile's page on GitHub Pages: https://maksio2019.github.io/ps5-spotify/
